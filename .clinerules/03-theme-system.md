
# DaliTak Theme System

Implement these six themes:
1. Light
2. Dark
3. Purple
4. Cyberpunk
5. Forest
6. Sunset

Requirements:
- Use CSS variables or the project's existing theme mechanism.
- Define tokens for backgrounds, surfaces, text, accents, borders,
  shadows, radii, and focus indicators.
- Apply tokens consistently across every relevant component.
- Provide a functional theme selector.
- Persist the selected theme in localStorage.
- Restore the saved preference on page reload.
- Avoid duplicating full stylesheets per theme.
- Verify contrast and readability in all six themes.
- Test theme switching, page reloads, and mobile layouts.
- Do not introduce a second theme library without justification.
