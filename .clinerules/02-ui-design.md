
# DaliTak UI and UX Rules

- Build on the existing architecture instead of rewriting it.
- Use consistent typography, spacing, color tokens, and components.
- Prioritize clarity, readability, and visual hierarchy.
- Use a clean sidebar, polished header, balanced cards, and
  clear navigation where appropriate to the existing app.
- Use subtle borders, shadows, gradients, and transitions.
- Avoid excessive glow effects, clutter, and unnecessary animation.
- Provide accessible labels, visible keyboard focus, and adequate
  text contrast.
- Respect reduced-motion preferences.
- Make layouts responsive on desktop, tablet, and mobile.
- Preserve the website's identity and existing interactions.
