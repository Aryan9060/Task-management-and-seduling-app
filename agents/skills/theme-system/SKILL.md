# Theme System Skill

1. Inspect the existing theme implementation first.
2. Establish semantic CSS variables for shared UI tokens.
3. Implement Light, Dark, Purple, Cyberpunk, Forest, and Sunset.
4. Use one theme mechanism across the application.
5. Add a clear, accessible theme selector.
6. Save and restore the selected theme using localStorage.
7. Avoid flash-of-wrong-theme behavior where practical.
8. Verify nested components, dialogs, forms, and navigation.
9. Check text contrast and focus visibility in every theme.
10. Test persistence and responsive behavior.
