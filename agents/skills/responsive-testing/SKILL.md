# Responsive Testing Skill

1. Verify the app starts using its existing development command.
2. Test desktop, tablet, and mobile viewport sizes.
3. Look for horizontal overflow, clipped cards, and overlapping text.
4. Test navigation, forms, dialogs, and primary interactions.
5. Test all six themes and theme persistence after reload.
6. Check keyboard navigation and focus visibility.
7. Inspect browser console errors when browser tooling is available.
8. Use Playwright MCP if connected; otherwise use available tests.
9. Fix regressions introduced by the redesign.
10. Record actual test results and any untested scenarios.
