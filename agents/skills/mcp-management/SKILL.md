# MCP Management Skill

1. Inspect existing MCP configuration before changing it.
2. Confirm the installed client and supported transport format.
3. Prefer trusted packages and official documentation.
4. Restrict filesystem access to required project directories.
5. Keep credentials in environment variables, never committed files.
6. Avoid broad auto-approval of shell or filesystem operations.
7. Verify server startup and exposed tool availability.
8. Diagnose missing executables, paths, permissions, and timeouts.
9. Never claim an MCP server is connected without verification.
10. Document setup, restart instructions, and remaining limitations.
