# UI/UX Design Skill

1. Inspect the current interface before proposing changes.
2. Identify visual hierarchy, spacing, typography, and navigation issues.
3. Prefer reusable components and design tokens.
4. Maintain a consistent visual language across pages.
5. Improve loading, empty, error, and hover states where applicable.
6. Ensure readable contrast, keyboard navigation, and focus states.
7. Use animation sparingly and respect reduced-motion preferences.
8. Avoid replacing working application functionality.
9. Compare the final interface against the provided design reference.
10. Verify changes in the running application when browser tools exist.
