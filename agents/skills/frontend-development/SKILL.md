# Frontend Development Skill

1. Detect the framework and package manager from existing files.
2. Inspect the relevant components before making changes.
3. Reuse existing utilities and dependencies.
4. Follow established naming and coding conventions.
5. Keep UI logic separate from styling where appropriate.
6. Preserve routes, APIs, authentication, and application state.
7. Avoid unnecessary dependencies and broad rewrites.
8. Inspect Git diffs before finishing.
9. Run available lint, build, and test scripts.
10. Report failures honestly and never claim an unrun test passed.
